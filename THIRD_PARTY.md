# Public dependencies

All application code for this submission was written in this repository during the build. No private pre-existing Airlock source was copied.

The package lock records exact public package versions. Principal dependencies are React, React DOM, Vite, TypeScript, Express, Zod, Lucide React, and their build and typing dependencies. Their upstream licenses remain applicable and are included in installed packages.

DM Sans and Manrope are bundled through Fontsource under the SIL Open Font License 1.1. Font license files are available in `node_modules/@fontsource-variable/dm-sans/LICENSE` and `node_modules/@fontsource-variable/manrope/LICENSE`. Fonts are served locally with the app, with no runtime Google Fonts request.

Sarvam supplies speech transcription and the default review model. Gemini is a manually selected backup. Each provider requires its own API key and available credits or quota for live requests.

The global Matt Pocock engineering skills and Cursor unslop writing skill guided the development process. They are not application runtime dependencies and their source is not copied into this repository.
